Обновлено: 7 ноября 2026 года. Ниже сохранены результаты отдельных исторических прогонов; они не являются измерениями одной сборки.

## Окружение

Windows x64, изолированное окружение CPython 3.11.18.

Проверены импорты: NumPy 2.4.6, PyAV 16.1.0, faster-whisper 1.2.1, sherpa-onnx 1.13.8, llama-cpp-python 0.3.19. Полный список — `requirements-tested.txt`.

## Автоматические проверки

Команда: `.venv/Scripts/python.exe -m unittest discover -s tests -v`.

**38 локальных автоматических тестов прошли в последней проверке**, включая:

- Реальное кодирование стереосигнала в MP3 44,1 кГц и декодирование в mono float32 16 кГц. Проверены длительность, конечность отсчётов и неизменность исходника.
- Отказ на повреждённом MP3.
- Совместимость конструкторов конфигурации с установленной sherpa-onnx.
- Отличие смены говорящего от одновременной речи; повторные интервалы одного голоса; unknown; объединение и разделение реплик; сохранение временной шкалы.
- Отклонение добавленных, удалённых, переставленных слов и посторонних символов из ответа LLM.
- Экспорт UTF-8 без BOM / LF, валидация времени, сохранение прежнего файла при ошибке проверки.
- Сценарии ASR/диаризация/LLM, повтор только LLM, отсутствие речи и нехватка памяти.

Дополнительно проверены точность границ нарезки MP3, неизменность исходника и сохранение прежнего результата при выходе за длительность записи.

Тесты `test_pipeline.py` используют подменённые модельные вызовы для проверки управления ошибками. Они не являются доказательством точности реальных моделей и не используются в рабочем CLI вместо инференса.

### Найденные проблемы и принятые настройки

1. **VAD терял короткую русскую фразу.** При включённом VAD рабочая конфигурация дала только `[Неразборчиво]`; без него ASR распознала слова. Поэтому `asr.vad_filter=false` — значение по умолчанию. После изменения повторены речь и тишина. На длинных/шумных файлах необходима дополнительная оценка ложных распознаваний.
2. **Избыточная кластеризация.** На публичной записи с четырьмя участниками длительностью 56,861 с порог 0,5 дал 7 групп. Значения 0,6, 0,7 и 0,8 дали по 4 группы и 13 интервалов. В конфигурации выбран 0,6. Правильное число групп не подтверждает правильность каждой реплики; DER не рассчитывался. Такая настройка по одному примеру не доказывает качество на русском.
3. **Отказ проверки LLM.** На английском примере один ответ отклонён/не принят, исходный ASR сохранён. Это ожидаемый безопасный сценарий, но он показывает ограниченность компактной LLM. Причина в журнале намеренно не включает текст модели.

## Проверка на локальном подкасте пользователя

Исходный MP3: stereo, 44,1 кГц, около 19 минут 34 секунд. В репозиторий не включены ни исходная запись, ни её название/локальный путь, ни текст расшифровки. Проверены только фрагменты, не полный выпуск.

1. Первый участок 00:00–01:00 содержит заставку и представление. Конвейер выдал 11 реплик, 4 голосовые группы, один участок unknown и 3 маркера неразборчивости. Поэтому этот участок не используется как подтверждение качества монолога. Повышение порога с 0,6 до 0,9 сокращало число групп, но общие настройки по нему не менялись.
2. Для проверки основного монолога отдельно вырезан участок **01:00–02:00**. С исходным автоматическим порогом **0,6**, без задания числа участников, получен **один speaker_1** и **5 реплик**. Unknown/overlap/маркеров неразборчивости нет.
3. Полное время второго участка: **63,020 с** на 60 с аудио, **RTF 1,050**. ASR: 18,096 с; диаризация: 16,594 с; LLM: 27,986 с. Из 5 текстов LLM приняты 4; для одной реплики использован исходный ASR после отказа генерации/проверки. JSON соответствует схеме.
4. Нарезка выполнена рабочими командами `cut` и `prepare-clips`, включая создание manifest.json со смещениями. Оригинал открывался только для чтения. Точность длительности и неизменность источника дополнительно проверяются автоматическими тестами.

Это подтверждает работоспособность конвейера на одном реальном монологе, но не точность текста: ручного эталона нет, WER не рассчитан. Этот прогон также не подтверждает качество смены участников. Частные результаты находятся в игнорируемом каталоге `artifacts/runs/`; обезличенные метрики — в `artifacts/test-results/podcast-monologue.metrics.json`.

## Эксперимент speech-guided


Получено 6 реплик и 3 голосовые группы. Прежнее разделение ведущего на два ID исчезло. Фраза «музыкальная заставка» не появилась; начало распознано как «Область знаний. Лекция на радиозвезда». Название станции осталось слитным, то есть точная запись слов ещё не восстановлена.

Прогон занял 49,165 с на 60 с аудио, RTF 0,819. LLM приняла 2 реплики; для остальных четырёх сохранён исходный ASR после отказа генерации/проверки. Это единичное измерение на компьютере, не доказательство ускорения относительно базового профиля.

Сохранились лексические ошибки. Повторная заставка перед началом лекции попала в группу ведущего; правильное количество групп не означает правильности каждого интервала. Полного ручного эталона нет, WER/DER не рассчитаны. Частные аудио и результаты не включены в Git.

## Ограничения

Если диаризация пропустит речь, ASR может не получить её за пределами padding. Поэтому профиль остаётся экспериментальным и не включён в базовую конфигурацию. Распознавание коротких контекстов тоже может галлюцинировать. Для общей оценки нужны дополнительные вступления, чистая речь, перебивания и ручная разметка.


## Эксперимент коротких реплик


В тестовом вступлении короткая заставка перед основным монологом относилась к голосу ведущего. Пользователь указал, что её произносит другой участник, speaker_2. Ручные изменения и предопределённые назначения ID исключены.

Новый профиль **автоматически отделил короткую заставку от ведущего**, но назначил её speaker_1, а не speaker_2. Поэтому точное исправление по пользовательской разметке **не достигнуто**. Результат не объявляется правильной диаризацией только из-за числа голосов или появления границы.

В реальном прогоне 00:00–01:00 получено 7 реплик, 3 группы и одно автоматическое переназначение короткого интервала. Заставка выделена примерно в 23,814–26,214 с, основной голос начинается примерно с 26,921 с. Это модельные оценки, не ручные границы.

Время — 56,937 с на 60 с аудио, RTF 0,949. LLM приняла 5 текстов, для двух сохранён ASR. Дополнительная обработка не является оптимизацией скорости. Прогон локальный; эталонные WER/DER отсутствуют. Метрики без текста находятся в `artifacts/test-results/short-turns.metrics.json`.
