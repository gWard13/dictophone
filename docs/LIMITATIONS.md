# Ограничения решения

## Распознавание и голоса

- Whisper small допускает пропуски и замены слов, особенно на шуме, музыке, перебиваниях и специальных терминах. Возможны выдуманные фразы на неречевом фоне.
- VAD выключен по умолчанию: на коротком русском примере он отбрасывал полезную речь. Агрессивная фильтрация не является универсальным улучшением.
- Диаризация может разделять одного человека на несколько групп и объединять разные голоса. Число групп не гарантирует правильность назначения каждой реплики.
- Короткие и обработанные эффектами голоса сложны. Экспериментальная перепроверка коротких интервалов отделила заставку от ведущего, но не подтвердила нужный пользователю ID. Косинусное сходство эмбеддингов не является вероятностью правильности.
- `overlap` обозначает одновременную речь, а не нового участника. Смешанные голоса отдельно не распознаются; наличие overlap зависит от интервалов диаризации.
- `[Неразборчиво]` формируется эвристически для целых речевых областей без ASR-слов. Возможны ложные срабатывания и пропущенные неразборчивые участки.
- ID стабильны только в пределах одной обработки. Между независимыми файлами и клипами участники не сопоставляются.

## Экспериментальные профили

Speech-guided ASR зависит от полноты речевой сегментации: пропущенная речь может оказаться за пределами контекстных окон. Короткий контекст также может галлюцинировать.

Профили `pipeline.speech-guided.json` и `pipeline.short-turns.json` не заменяют базовый автоматически. Их проверяли на ограниченном числе фрагментов. История и фактические результаты — в [TEST_RESULTS.md](TEST_RESULTS.md).

## LLM

LLM разрешены только регистр и пунктуация. Исправление распознанных слов отключено, хотя исходное ТЗ допускает очевидные исправления ASR. Поэтому ошибка слова может сохраниться после LLM. При отклонённом ответе используется исходный ASR; правильность пунктуации и смысла не гарантируется.

## Ресурсы и файлы

- Проверена desktop-версия на Windows/CPU. Работа на Android, бюджет 4 ГБ ОЗУ, скорость и энергопотребление телефона не проверялись. Итоговое приложение не должно использовать Python-сервер на компьютере.
- Модели могут создавать копии аудио и большие промежуточные тензоры. Memory map не гарантирует постоянный расход памяти. Произвольная длительность файла не гарантируется.
- Диаризация работает по всей записи; независимые куски без сопоставления голосов не реализованы.
- CLI принимает MP3. Для точной нарезки создаётся новый MP3 mono 16 кГц, то есть выполняется повторное сжатие. Оно может повлиять на распознавание.
- При штатном завершении/ошибке временный PCM удаляется. После принудительного завершения процесса временные каталоги могут остаться; автоматической очистки осиротевшего кэша нет.
- Физическое отключение сети на компьютере при модельных тестах не проводилось. Код использует локальные пути, offline-режим и не вызывает сервисы распознавания.

## Воспроизводимость и оценка

Установщик по умолчанию использует ревизии моделей `main`, а pyproject задаёт диапазоны зависимостей. Для повторения фиксируйте commit hash весов, их SHA-256 и окружение. `requirements-tested.txt` относится к Windows x64 / Python 3.11, включая платформенный wheel LLM.

Результаты времени — единичные измерения на компьютере, не норматив и не прогноз для телефона. Полные ручные эталоны не подготовлены; WER и DER на пользовательских разговорах не заявляются. Автоматические тесты проверяют код, а не точность моделей.

Конфигурации и веса считаются доверенными. Аудио, сессии, расшифровки, локальные настройки и модели исключены из Git. Лицензии библиотек и весов проверяются отдельно; исходным файлам проекта лицензия автоматически не назначена.

## Подготовленный Kotlin-комплект

Подготовлены publisher-converted Whisper small GGML F16/Q5_1 и Kotlin-алгоритмы, но APK/JNI-адаптеры и запуск на эмуляторе не проверены. 58 JVM-контрольных случаев не заменяют Android-тестирование. Модельные результаты CTranslate2 и whisper.cpp не обязаны совпадать; в whisper.cpp метки слов требуют отдельной проверки.

4 ГБ — общий объём эмулятора, не бюджет одной программы. Сумма размеров весов на диске не равна пику RAM. Измеренный пик рабочего набора отдельного Windows ASR-процесса составил около 481 МиБ для Q5_1 и 769 МиБ для F16; это не измерение Android и не память всего конвейера. На Windows Q5_1 оказался медленнее F16 в проверенных коротких прогонах, поэтому квантование не объявляется ускорением на ARM.

ABI и RAM-профиль Pixel 10 / API 37 указаны пользователем, фактический эмулятор здесь не подключался. Требуются проверка ABI через adb, сборка native-библиотек, измерения памяти/времени на AVD и тест без сети. Графиков обучения, WER/DER и Android RAM нет: эти данные не измерены.
