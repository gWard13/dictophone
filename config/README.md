# Конфигурации

- `pipeline.example.json` — параметры ASR, диаризации и LLM. Относительные пути считаются от каталога конфигурации. Скопируйте в `pipeline.local.json` для своих настроек.
- `pipeline.speech-guided.json` — экспериментальный профиль: диаризация до ASR, контекстные окна вокруг речевых интервалов, порог кластеризации 0,8. Может улучшать музыкальные заставки, но зависит от ошибок сегментации; не заменяет базовый профиль автоматически.
- `pipeline.short-turns.json` — дополнительная экспериментальная перепроверка голосов коротких интервалов. На проверенном вступлении отделяет заставку от ведущего, но не подтверждает требуемое пользователем назначение speaker_2. Использует исходную модель эмбеддингов; дополнительные веса для запуска не нужны.
- `podcast_clips.example.json` — только пример плана нарезки. Интервалы не проверялись на конкретном выпуске. Укажите существующий локальный MP3, источник и реальные интервалы; сохраните как `podcast_clips.local.json`.
- Формат экспорта описан в `../transcript.schema.json`.

Настройки `*.local.json` не включаются в Git.

Результаты профилей собраны в [TEST_RESULTS.md](../docs/TEST_RESULTS.md), ограничения — в [LIMITATIONS.md](../docs/LIMITATIONS.md). Основной пример настроек хранится только в этом каталоге.
