# Конфигурации

- `pipeline.example.json` — параметры ASR, диаризации и LLM. Относительные пути считаются от каталога конфигурации. Скопируйте в `pipeline.local.json` для своих настроек.
- `podcast_clips.example.json` — только пример плана нарезки. Интервалы не проверялись на конкретном выпуске. Укажите существующий локальный MP3, источник и реальные интервалы; сохраните как `podcast_clips.local.json`.
- Формат экспорта описан в `../transcript.schema.json`.

Настройки `*.local.json` не включаются в Git.
