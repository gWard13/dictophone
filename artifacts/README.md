# Артефакты

- `validation/` — проверенные обезличенные метрики предыдущих локальных прогонов, без аудио и текста.
- `model-manifest.json` — размеры и SHA-256 фактически подготовленных весов.
- `runs/` — новые расшифровки, сессии, отчёты. Каталог игнорируется Git.

Результаты на подкастах являются реальными только после запуска; наличие примера конфигурации не означает проведённый тест. Не включайте записи, расшифровки и имена приватных файлов в публичный репозиторий автоматически.
