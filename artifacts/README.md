# Артефакты проверок

- `model-manifest.json` — размеры, источники и SHA-256 подготовленных основных весов; сами модели не включены в Git.
- `test-results/summary.csv` — сводная таблица имеющихся измерений. Пустые поля означают отсутствие измерения, а не ноль.
- `test-results/*.json` — подробные исходные метрики и результаты подбора порогов, без аудио и текста. Названия файлов сохранены при переносе из прежнего validation.
- `runs/` — новые приватные расшифровки, сессии и отчёты; каталог игнорируется Git.

Контекст и ограничения измерений: [TEST_RESULTS.md](../docs/TEST_RESULTS.md). Частные аудио, их пути и тексты автоматически не публикуются. Не каждая локальная проверка включена в эти отчёты.
